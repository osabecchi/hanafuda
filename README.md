# 花暦 HANAGOYOMI(はなごよみ)

花札で役を作って点を稼ぐ、考える系のローグライク。
手札8枚から札を選んで「出す」と、できた役の点数×倍率がスコアになる。目標の点に届けば勝ち。1か月は3勝負(一・二・主)、十二か月を乗り切れば1年クリア。

**遊ぶ:** https://osabecchi.github.io/hanafuda/

## 遊び方

- 札を最大5枚選んで「出す」。できた役は**すべて重ねて**数える(例: 赤短+タン+花暦)
- 得点 =(役の点 + 札の点)×(役の倍)。札の点は 光20・タネ10・短冊5・カス1、その月の札(旬)は +10
- 出しと捨ての回数には限りがある。一・二の勝負の相手は「お題」を出し、主は特別な決まりで邪魔をしてくる
- 勝つと「ご褒美」(3択)、主を倒すと「縁起物」(3択)と「茶屋」での買い物
- 神札(5枠)は持っているだけで効き、左から順に計算される。特定の組み合わせで「進化」する
- 旅の終わりに金箔がたまり、「蔵」で永久強化と新しいデッキを手に入れる

## 中身

- 役 25種(五光・四光・雨四光・三光・猪鹿蝶・赤短・青短・草短・月見酒・花見酒・表菅原・松桐坊主・光一・花暦・タネ・タン・カス・手四・三本 など)
- 神札 86種 + 進化 15種(並・上・極・幻)、お守り 27種(絵馬・加工・特別)、縁起物 18種
- 相手 18種、主 21体(各月の主 12 + どの月にも出る主 9)
- 開始デッキ 8種(花・朱・藍・金・暦・八八・こいこい・乱れ)、段位 8段階
- 実績 32、図鑑(神札の解放条件つき)、記録、エンドレス(二年目以降)、デイリー(日替わりで全員同じ展開)

## スマホのホーム画面にアプリとして追加する

ホーム画面に追加できる形(PWA)になっています。一度開いたあとはオフラインでも遊べます。

- iPhone: Safari で上の URL を開き、共有ボタン →「ホーム画面に追加」
- Android: Chrome で開き、メニュー →「ホーム画面に追加」(または「アプリをインストール」)

## ファイル構成

ビルドは不要です。`index.html` を開くとそのまま遊べます。

- `index.html` — 画面とスタイル
- `js/` — core(セーブ・音)、data(数値とコンテンツ)、rules(役の判定と得点)、run(旅の進行)、art(札の絵)、fx(演出)、ui(勝負の画面)、screens(メニュー)、main(起動)
- `tools/bot.js` — 画面なしで遊ぶテスト用ボット(`node tools/bot.js 40 hana 1`)
- `tools/sheet.html` — 札の絵の一覧(確認用)
- `manifest.webmanifest` / `sw.js` / `icons/` — ホーム画面アプリ用
- 進行状況はブラウザーの localStorage(`hanagoyomi-save-v1`、中断中の旅は `hanagoyomi-run-v1`)に保存されます
